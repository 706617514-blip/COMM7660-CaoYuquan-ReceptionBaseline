# 装备系统设计文档

日期：2026-11-11
规模：项目级（约 6–7 天工作量）
状态：待 PM 批准

---

## 1. 意图与原因

**要解决的问题：** 当前金币经济在约 12 局（约 7 分钟）后就失去意义。一局产出 228 铜币，
买满全部强化与技能共需 2,708 铜币。买满之后没有任何消费出口，游戏的经济循环终止。

**为什么不只是"加更多装备"：** 增加一次性购买只能把 12 局延长到 20 局，仍然是有限的。
需要的是**可重复消费**，而不是更多一次性商品。

**这个系统的目标：**

1. 给金币一个**不会枯竭**的出口
2. 让装备选择**反映打法**而不是数值大小
3. 保持视觉可辨识：穿不同装备必须看得出不同

**非目标：**

- 不做随机词条（洗练）。它会引入不可控的平衡问题，而剩余时间不足以调。
- 不做装备耐久/损坏。惩罚性机制会拖慢节奏。
- 不做交易或合成。超出范围。

**反目标（这样做就算失败）：**

- 如果玩家发现"存在唯一最优装备组合"，系统就退化成了数值比较
- 如果装备视觉效果在 40×60px 下分辨不出，就是白做

## 3. 方案选择

### 装备 vs 现有铁匠铺的关系

| 方案 | 说明 | 结论 |
|---|---|---|
| A. 装备是第三层（纯数值叠加） | 铁匠铺 + 祭坛 + 装备，三层都加属性 | 拒绝：数值失控，且三层无区别 |
| B. 装备取代铁匠铺 | 把永久升级改成可换装备 | 拒绝：动到现有存档与全部测试，风险高 |
| **C. 装备走特殊效果** | 铁匠铺管基础属性，装备管**独特机制** | **采纳**（PM 选择） |

### 消耗机制

| 方案 | 说明 | 结论 |
|---|---|---|
| 1. 装备可升级 | 每件 3–5 级，效果递增 | **采纳** |
| 2. 洗练/重铸 | 随机重roll附加属性 | 拒绝：随机属性让平衡不可控 |
| **3. 消耗品** | 战斗中可用的药水，每局都要买 | **采纳** |

**采纳 1 + 3**（PM 选择）。方案 1 把一次性购买变成长线投入，方案 3 提供**永远不会买满**的出口。

### 技能与装备的关系

| 方案 | 说明 | 结论 |
|---|---|---|
| 全部改造现有技能 | 成本低，不动架构 | 不够：缺少"换打法"的驱动力 |
| 全部解锁新技能 | 爽快，但平衡难调 | 拒绝：装备可换，等于白送手段 |
| **混合** | 多数改造，少数解锁且占武器位 | **采纳**（PM 选择） |

## 4. 设计

### 4.1 装备位

**五个部位**：头 / 躯干 / 背 / 武器 / 鞋

五个都有明显视觉差异，已通过预览页确认。

### 4.2 装备数量与价格

| 类别 | 数量 | 价格区间 | 说明 |
|---|---|---|---|
| **基础装备** | 16 件（4 部位 × 4 档，武器 5 档） | 80–900 | 主要是属性倾向，视觉靠轮廓区分 |
| **特效装备** | 12 件 | 680–900 | 数值接近，**差异全在效果** |

基础装备扩到 16 件是为了让 5% 掉落能持续 10+ 局（原 4 件会被 2–3 局掉完）。

### 4.3 获取方式

| 途径 | 规则 |
|---|---|
| **商店购买** | 铜币买，价格固定 |
| **小怪掉落** | **5%** 概率，**只掉基础装备**（不掉特效装备） |
| **重复品处理** | 已有的装备自动折算成 **30% 原价**铜币 |

**为什么重复品要折算：** 否则玩家掉完 16 件后，掉落就完全没价值了，金币出口又断掉。

**为什么不掉特效装备：** 特效装备是"目标"，需要攒钱买；掉落会让它失去稀缺性。

### 4.4 装备升级

每件装备 **3–5 级**，效果随等级递增（约 +8% 效果/级），价格按 1.45 倍递增。

- 基础装备：3 级
- 特效装备：5 级（因为效果是机制，升级要与数值挂钩时要克制）

**关键：特效装备的升级只提升"强度参数"，不改变机制。**
例如反伤 30% → 34% → 38%，但永远是"反伤"，不会变成别的东西。

### 4.5 消耗品（药水）

| 药水 | 效果 | 价格 | 每局携带上限 |
|---|---|---|---|
| 回春药 | 立刻回 25 血 | 60 | 3 |
| 力量药 | 15 秒内伤害 +25% | 80 | 2 |
| 坚壁药 | 8 秒内受伤 −50% | 90 | 2 |

- **战斗中按键使用**（数字键 1/2/3 或单独的 Q 键，待定）
- 每局开始时可携带，**用掉就没了**，下一局要重新买
- **这是永远不会枯竭的出口**

### 4.6 技能改造（多数装备）

装备**修改已有技能的行为**，不改基础数值：

| 装备 | 改造 |
|---|---|
| 战斧 | 震地范围 +50%，但冷却 +15% |
| 虚空之刃 | 裂风斩附加吸血（伤害的 15% 回血） |
| 霜缚护甲 | 闪现落点留冰霜（减速范围） |
| 雷鸣角盔 | 第 3 段普攻附带电击（小范围） |
| 熔火战靴 | 震地灼烧（持续伤害） |
| 三叉圣杖 | 大招范围 +20% |

### 4.7 专属技能（少数装备）

**只做 2–3 件**，且**占用武器位**（不能同时带剑），所以是**替换**而非白送。

| 装备 | 专属技能 | 键位 | 与现有技能的差异 |
|---|---|---|---|
| 守誓者 | **格挡**（举盾，2 秒内减伤 70%，不能移动） | V | 提供现有技能没有的"站定防御" |
| 秘法之书 | **短距传送**（前冲 240px 无敌） | V | 比闪现更远但无伤害 |

**约束：** 专属技能强度必须**低于**对应位置的现有武器所提供的输出，
否则"装上就多一个技能"等于白送。

**技能栏动态显示：** 没装备该武器时，那个技能格子不显示。

### 4.8 存档结构变化

```js
meta: {
  coins, seeds, upgrades, skills, runsCompleted, runsWon, bestWave,
  // 新增
  equipment: {
    head: null | { id: 'ironHelm', level: 2 },
    torso: null | { id: 'plateArmor', level: 1 },
    back: null | { id: 'runeCloak', level: 3 },
    weapon: null | { id: 'battleAxe', level: 1 },
    feet: null | { id: 'windBoots', level: 2 },
  },
  inventory: ['leatherHelm', 'shortCape', ...],   // 已拥有但未装备
  potions: { heal: 2, strength: 0, wall: 1 },     // 当前携带
}
```

**版本迁移：** `STATE_VERSION` 3 → 4，`migrate()` 补空装备位与空背包。

### 4.9 数值平衡约束

| 约束 | 理由 |
|---|---|
| 特效装备价格挤在 680–900 | 让玩家按打法选，不是按数值选 |
| 任何特效装备的强度不超过基础装备的 1.3 倍（按等效数值估） | 防止出现唯一最优解 |
| 专属技能的 DPS 低于同级武器 | 防止"A+技能"组合碾压 |
| 药水每局消耗约 200 铜币 | 与一局产出 228 铜币大致相抵，让玩家必须选择 |

## 5. 视觉效果

**已通过预览页确认**（`/tmp/equip_preview/`，非仓库文件）。

| 部位 | 区分手段 | 已验证 |
|---|---|---|
| 头 | 轮廓（圆盔 / 护颊 / 角盔） | ✓ 40px 可辨 |
| 躯干 | 款式（胸甲 / 肩甲 / 全身板甲） | ✓ |
| 背 | 长度与宽度 | ✓ |
| 武器 | 形状（剑 / 斧 / 双刀 / 棱晶杖 / 三叉权杖） | ✓ |
| 鞋 | 轮廓外扩 + 装饰（翼片 / 护膝 / 绑带） | ✓ 但绑带偏糊 |
| 特效 | **10 种不同形状**（尖刺 / 血滴 / 闪电 / 火星 / 雪花 / 残影 / 护盾 / 虚空环 / 晶片 / 光柱） | ✓ |

**待修：** 磐石靴绑带偏糊、虚空之刃偏暗。

**实现方式：** 复用预览页的绘制代码，接入 Phaser 的 `Graphics` 生成纹理，
但装备是**动态叠加**的（随装备变化），所以不能提前 `generateTexture` ——
需要一个**运行时合成**：身体纹理 + 装备层逐帧叠加，或用 Phaser 的 Container 分层。

## 6. 测试计划

**必须可测（写成断言）：**

| 行为 | 为什么必须测 |
|---|---|
| 装备加成正确生效 | 核心功能 |
| 特效装备的机制真的触发 | 否则只是换了个名字 |
| 技能改造改变技能行为 | 否则玩家买了没变化 |
| 专属技能只在装备时可用 | 否则等于白送 |
| 掉落率在配置值附近 | 5% 是明确要求 |
| 重复掉落折算 30% | 经济闭环的关键 |
| 装备升级效果递增 | 否则升级没意义 |
| 药水用掉后减少 | 消耗机制的核心 |
| 存档迁移（v3 → v4） | 旧档不能丢 |
| 卸下装备后技能消失 | 动态技能栏的正确性 |

**不测（明确说明）：**

- 视觉效果（靠截图人工核对，见 `docs/browser-test-evidence.md` 的说明）
- 平衡手感（靠 bot 测量，见 `tests/balance_report.js`）

# 武器挂载规格（解决"武器乱飞"）

## 问题是什么

**现象**：装备武器后，剑/斧的位置和角色手的位置对不上。

**根因**（已核实代码）：武器是**一张 40×60 的整图**，内容画在
`(5,14,35,46)`，与角色共用同一个锚点 `setOrigin(0.5, 1)`。

这等于假设了一件事：**"手的位置永远不变"**。
但角色在战斗里会挥砍、跑动、受击，手会动 —— 武器不跟，于是错位。

## 为什么 Boss 的手臂没这个问题

Boss 的手臂**不是贴图**，是 `bosspose.js` 用**纯函数算出来再画**的：

```
BossPose.compute({dx, dz, casting, facing, phase, dt, time, charge})
  → 返回 pose { bob, squash, lean, armRaise, armSwing, armPhase, footfall }
  → 渲染层把数值变成像素
```

**关键**：手臂的每个部分都从**同一个姿态函数**取值，
所以身体动、手臂必然跟着动，永远不会错位。
而且它有 **9 条不变量测试**钉着（`tests/test_bosspose.js`），改坏了立刻红。

## 新画风应该怎么做

### 方案：武器分两段，挂在计算出的手上

| 部件 | 做法 | 为什么 |
|---|---|---|
| **角色本体** | 一张图（含手） | 手的位置由这张图定 |
| **武器** | **独立小图**，锚点 = 握把底部 | 不是整张 40×60，而是**只有武器本身** |
| **挂载点** | 由姿态函数算出的**手部坐标** | 与 Boss 手臂同一原理 |
| **朝向** | 跟着 `facing` 翻转（现有 `setFlipX` 机制） | 已解决"人朝左剑朝右" |

### 三条硬规则

| # | 规则 | 依据 |
|---|---|---|
| W1 | **武器的锚点在握把**（`setOrigin` 指向手握的位置），不是图片中心 | 锚点错了，任何旋转都会把武器甩出去 |
| W2 | **武器图和角色图分开**，不叠成同一张 | 合成一张 = 位置写死 = 必然错位 |
| W3 | **握把坐标由姿态函数给出**，不在渲染层写死常量 | 与 Boss 手臂同一模式；写字面值就会在下一次改姿态时失效 |

### 与既有架构的关系

- 现有 `EQUIP_LAYER_ORDER = ['back','torso','feet','head','weapon']` **保留**
- 但 weapon 层的图从"整张 40×60"改为"只有武器的小图 + 握把锚点"
- 现有的 `setFlipX` 逐层镜像机制**继续用**（它已经解决了左右翻转）

### 验收判据（必须实测，不能只看截图）

| # | 判据 |
|---|---|
| V1 | 待机时，手握在武器握把上（缩放 5 倍目视） |
| V2 | 挥砍时，武器跟着手走（连续截 3 帧对比） |
| V3 | 朝左时，武器正确镜像（不出现"人朝左剑朝右"） |
| V4 | 4 种武器（剑/斧/法杖/三叉戟）握把位置都对得上 |
